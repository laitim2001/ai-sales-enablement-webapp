# UI Components - React & Shadcn/ui

## 核心模式

### 客戶端組件
```typescript
'use client'

export function MyComponent() {
  const [state, setState] = useState<T>()
  const { user } = useAuth()

  useEffect(() => {
    fetchData()
  }, [])

  return <Card>...</Card>
}
```

### 權限控制組件
```typescript
import { usePermission } from '@/hooks/use-permission'

export function ProtectedButton() {
  const canDelete = usePermission(Resource.CUSTOMERS, Action.DELETE)

  return canDelete ? <Button>刪除</Button> : null
}
```

### 表單處理
```typescript
import { useForm } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'

const schema = z.object({ title: z.string().min(1) })

export function MyForm() {
  const form = useForm({
    resolver: zodResolver(schema)
  })

  async function onSubmit(data: z.infer<typeof schema>) {
    await api.post('/api/resource', data)
  }
}
```

## UI標準

- **組件庫**: Shadcn/ui + Radix UI
- **樣式**: Tailwind CSS
- **圖標**: Heroicons
- **表單**: React Hook Form + Zod
- **狀態**: useState + useEffect (簡單) / Zustand (複雜)

## 關鍵約定

1. **'use client'**: 需要交互的組件必須標記
2. **類型定義**: Props和State必須有TypeScript類型
3. **錯誤邊界**: 使用 `<ErrorBoundary>` 包裹
4. **加載狀態**: 提供 `loading` 和 `error` UI
5. **響應式**: 使用Tailwind斷點 `md:`, `lg:`

## 依賴關係

- `@/components/ui` - 基礎UI組件
- `@/hooks` - 自定義Hooks
- `@/lib/api` - API調用

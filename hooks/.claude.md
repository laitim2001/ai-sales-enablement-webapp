# React Hooks - Custom Hooks

## 核心模式

### 認證Hook
```typescript
import { useAuth } from '@/hooks/use-auth'

export function MyComponent() {
  const { user, loading, login, logout, refreshAuth } = useAuth()

  if (loading) return <Loading />
  if (!user) return <Login onLogin={login} />

  return <div>Welcome {user.email}</div>
}
```

### 權限Hook
```typescript
import { usePermission } from '@/hooks/use-permission'

export function ProtectedButton() {
  const canDelete = usePermission(Resource.CUSTOMERS, Action.DELETE)
  const canEdit = usePermission(Resource.CUSTOMERS, Action.UPDATE)

  return (
    <>
      {canEdit && <Button>編輯</Button>}
      {canDelete && <Button variant="destructive">刪除</Button>}
    </>
  )
}
```

### Toast通知Hook
```typescript
import { useToast } from '@/hooks/use-toast'

export function MyForm() {
  const { toast } = useToast()

  async function handleSubmit() {
    try {
      await api.post('/api/resource', data)
      toast({
        title: "成功",
        description: "資源已創建",
        variant: "success"
      })
    } catch (error) {
      toast({
        title: "錯誤",
        description: error.message,
        variant: "destructive"
      })
    }
  }
}
```

## 文件結構

- `use-auth.ts` - 認證狀態管理
- `use-permission.ts` - 權限檢查
- `use-toast.ts` - Toast通知

## Hook規範

### 命名規則
- 必須以 `use` 開頭
- 使用camelCase命名
- 描述性名稱: `useAuth`, `usePermission`

### 返回模式
```typescript
// 單值返回
export function useUser() {
  return user
}

// 對象返回 (推薦)
export function useAuth() {
  return { user, loading, login, logout }
}

// 數組返回
export function useToggle(initial: boolean) {
  return [value, toggle]
}
```

## 關鍵約定

1. **依賴注入**: Hook內部不直接訪問Context，通過參數傳入
2. **錯誤處理**: Hook內部catch錯誤，返回error狀態
3. **清理資源**: useEffect返回cleanup函數
4. **記憶化**: 使用useMemo和useCallback優化性能
5. **測試友好**: Hook邏輯可獨立測試

## 依賴關係

- `react` - React核心
- `lib/auth` - 認證服務

# Prisma - Database Schema & ORM

## 核心模式

### Prisma客戶端
```typescript
import { prisma } from '@/lib/prisma'

// CRUD操作
const user = await prisma.user.create({
  data: { email, password, role }
})

const users = await prisma.user.findMany({
  where: { role: 'SALES_REP' },
  include: { proposals: true },
  orderBy: { createdAt: 'desc' },
  take: 20,
  skip: 0
})

await prisma.user.update({
  where: { id },
  data: { status: 'INACTIVE' }
})

await prisma.user.delete({ where: { id } })
```

### 關聯查詢
```typescript
// 嵌套include
const proposal = await prisma.proposal.findUnique({
  where: { id },
  include: {
    customer: true,
    createdBy: true,
    versions: {
      orderBy: { versionNumber: 'desc' },
      take: 5
    },
    approvals: {
      include: { approver: true }
    }
  }
})
```

### 事務處理
```typescript
// 多操作事務
const result = await prisma.$transaction(async (tx) => {
  const proposal = await tx.proposal.create({ data: proposalData })
  await tx.auditLog.create({ data: auditData })
  return proposal
})

// 交互式事務（推薦）
await prisma.$transaction([
  prisma.user.create({ data: userData }),
  prisma.auditLog.create({ data: auditData })
])
```

## Schema結構

### 主要模型
```prisma
model User {
  id        Int      @id @default(autoincrement())
  email     String   @unique
  role      Role     @default(SALES_REP)
  createdAt DateTime @default(now())

  // 關聯
  proposals Proposal[]
  auditLogs AuditLog[]
}

model Customer {
  id          Int      @id @default(autoincrement())
  name        String
  status      String   @default("ACTIVE")

  // 關聯
  proposals   Proposal[]
  interactions Interaction[]
}

model KnowledgeBase {
  id        Int      @id @default(autoincrement())
  title     String
  content   String   @db.Text
  embedding Float[]  // pgvector
  category  Category
  status    Status   @default(ACTIVE)

  // 索引
  @@index([status])
  @@index([category])
  @@map("knowledge_base")
}
```

## 遷移管理

### 開發環境
```bash
# 創建遷移
npx prisma migrate dev --name add-user-role

# 重置數據庫
npx prisma migrate reset

# 生成客戶端
npx prisma generate
```

### 生產環境
```bash
# 部署遷移
npx prisma migrate deploy

# 推送Schema變更（無遷移文件）
npx prisma db push
```

## 關鍵約定

1. **單例模式**: 使用 `lib/prisma.ts` 導出全局實例
2. **類型生成**: 每次Schema變更後運行 `prisma generate`
3. **遷移命名**: 描述性名稱 `add-customer-status-field`
4. **索引優化**: 為常用查詢字段添加索引
5. **軟刪除**: 使用 `deletedAt` 而非真刪除
6. **枚舉使用**: 狀態字段使用Prisma枚舉保證一致性

## 依賴關係

- `@prisma/client` - 生成的客戶端
- `prisma` - CLI工具
- PostgreSQL 14+ - 數據庫
- pgvector - 向量擴展

# Parsers Module - Multi-Format Document Parsing

## 核心模式

### 統一解析接口
```typescript
// 自動識別格式並解析
const result = await parseDocument(buffer, mimeType)
// 返回: { text: string, metadata: object }

// 批量解析
const results = await parseDocuments(files)
```

### 支持的格式
```typescript
const SUPPORTED_FORMATS = {
  'application/pdf': parsePDF,
  'application/vnd.openxmlformats-officedocument.wordprocessingml.document': parseWord,
  'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet': parseExcel,
  'application/vnd.openxmlformats-officedocument.presentationml.presentation': parsePowerPoint,
  'text/plain': parseText,
  'text/csv': parseCSV,
  'image/png': parseImage,  // OCR
  'image/jpeg': parseImage
}
```

## 文件結構

- `unified-parser.ts` - 統一解析接口
- `pdf-parser.ts` - PDF解析 (pdf-parse)
- `word-parser.ts` - Word解析 (mammoth)
- `excel-parser.ts` - Excel解析 (xlsx)
- `image-parser.ts` - 圖片OCR (Tesseract)

## 解析配置

### PDF
```typescript
{
  maxPages: 500,
  extractImages: false,
  preserveLayout: true
}
```

### Word
```typescript
{
  convertImage: false,
  ignoreEmptyParagraphs: true
}
```

### Excel
```typescript
{
  sheetNames: ['Sheet1'], // 指定工作表
  header: 1,              // 第一行為標題
  raw: false              // 格式化數字和日期
}
```

## 關鍵約定

1. **MIME驗證**: 使用 `file-type` 庫雙重驗證
2. **大小限制**: 單文件最大50MB
3. **錯誤處理**: 解析失敗返回空文本而非拋錯
4. **元數據提取**: 返回頁數、字數、作者等信息
5. **異步處理**: 大文件使用Worker線程

## 依賴關係

- `pdf-parse` - PDF解析
- `mammoth` - Word文檔
- `xlsx` - Excel工作簿
- `tesseract.js` - OCR識別
- `file-type` - MIME類型檢測

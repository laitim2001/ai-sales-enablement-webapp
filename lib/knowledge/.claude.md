# Knowledge Base Module - Full-Text & Vector Search

## 核心模式

### 混合搜索
```typescript
// 全文搜索 + 向量搜索
const results = await hybridSearch({
  query: "客戶管理",
  filters: { category: 'SALES_MATERIAL', status: 'ACTIVE' },
  limit: 20,
  offset: 0
})
```

### CRUD操作
```typescript
// 創建文檔（自動生成向量）
const doc = await createKnowledgeDocument({
  title, content, category, tags
})

// 更新（重新生成向量）
await updateKnowledgeDocument(id, { content })

// 查詢（支持多重過濾）
const docs = await getKnowledgeDocuments({ status, category })
```

## 文件結構

- `full-text-search.ts` - PostgreSQL FTS
- `vector-search.ts` - pgvector相似度搜索
- `knowledge-service.ts` - CRUD業務邏輯

## 搜索策略

- **關鍵詞**: PostgreSQL `to_tsvector()`
- **語義**: pgvector cosine similarity
- **混合**: 加權平均 (0.7 * vector + 0.3 * fts)
- **過濾**: category, status, tags, dateRange

## 關鍵約定

1. **自動向量化**: 創建/更新時自動調用 `generateEmbedding()`
2. **分頁必須**: 大結果集必須使用 `limit/offset`
3. **緩存策略**: 熱門搜索結果緩存5分鐘
4. **標籤管理**: 使用中間表 `knowledge_base_tags`

## 依賴關係

- `lib/ai` - 向量生成
- `lib/parsers` - 文檔解析
- `@prisma/client` - 數據庫訪問

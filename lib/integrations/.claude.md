# Integrations Module - CRM & Microsoft Graph

## 核心模式

### Dynamics 365 整合
```typescript
// 同步客戶數據
const customer = await dynamics365Service.syncCustomer(customerId)

// 獲取360度視圖
const view360 = await dynamics365Service.getCustomer360View(customerId)

// OAuth認證
const token = await getDynamics365AccessToken()
```

### Microsoft Graph 日曆
```typescript
// 獲取用戶日曆
const events = await graphService.getCalendarEvents(userId, startDate, endDate)

// 創建會議
const meeting = await graphService.createMeeting({
  subject: "客戶會議",
  attendees: [email1, email2],
  start: new Date(),
  duration: 60
})
```

## 整合配置

### Dynamics 365
- **端點**: `https://{org}.crm5.dynamics.com`
- **認證**: OAuth 2.0 Client Credentials
- **範圍**: `https://{org}.crm5.dynamics.com/.default`

### Microsoft Graph
- **端點**: `https://graph.microsoft.com/v1.0`
- **認證**: OAuth 2.0 (Delegated或Application)
- **權限**: `Calendars.ReadWrite`, `User.Read`

## 關鍵約定

1. **Token管理**: 使用 `@azure/msal-node` 自動刷新
2. **錯誤重試**: 外部API調用必須有重試機制
3. **數據映射**: 使用適配器模式轉換外部數據格式
4. **同步策略**: 增量同步優先，定時全量同步
5. **斷路器**: 使用Circuit Breaker防止級聯故障

## 依賴關係

- `@azure/msal-node` - Microsoft認證
- `axios` - HTTP客戶端
- `lib/resilience` - 重試和斷路器

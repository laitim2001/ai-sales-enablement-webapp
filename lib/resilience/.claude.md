# Resilience Module - Circuit Breaker & Retry

## 核心模式

### 斷路器
```typescript
import { CircuitBreaker } from '@/lib/resilience/circuit-breaker'

const breaker = new CircuitBreaker({
  failureThreshold: 5,    // 5次失敗後開啟
  successThreshold: 2,    // 2次成功後關閉
  timeout: 30000,         // 30秒超時
  resetTimeout: 60000     // 1分鐘後嘗試半開
})

// 包裝外部API調用
const result = await breaker.execute(async () => {
  return await externalAPI.call()
})
```

### 重試機制
```typescript
import { withRetry } from '@/lib/resilience/retry'

// 自動重試失敗的操作
const result = await withRetry(
  async () => await unstableOperation(),
  {
    maxRetries: 3,
    backoff: 'exponential', // 指數退避
    initialDelay: 1000,     // 初始1秒
    maxDelay: 10000,        // 最大10秒
    retryableErrors: [TimeoutError, NetworkError]
  }
)
```

### 健康檢查
```typescript
import { HealthCheck } from '@/lib/resilience/health-check'

const health = new HealthCheck({
  checks: [
    { name: 'database', fn: checkDatabase },
    { name: 'redis', fn: checkRedis },
    { name: 'openai', fn: checkOpenAI }
  ],
  interval: 30000 // 每30秒檢查
})

// 獲取健康狀態
const status = await health.getStatus()
// { healthy: true, checks: [...] }
```

## 文件結構

- `circuit-breaker.ts` - 斷路器實現
- `retry.ts` - 重試策略
- `health-check.ts` - 健康檢查

## 斷路器狀態

```
CLOSED (正常)
   ↓ 失敗次數 >= threshold
OPEN (斷開)
   ↓ resetTimeout後
HALF_OPEN (半開)
   ↓ 成功次數 >= successThreshold
CLOSED (恢復)
```

## 重試策略

### 線性退避
```typescript
delay = initialDelay * attemptNumber
```

### 指數退避（推薦）
```typescript
delay = min(initialDelay * 2^attemptNumber, maxDelay)
```

### Jitter（抖動）
```typescript
delay = baseDelay + random(0, jitterRange)
```

## 關鍵約定

1. **外部依賴**: 所有外部API調用必須使用斷路器
2. **冪等操作**: 重試的操作必須是冪等的
3. **錯誤分類**: 區分可重試錯誤和不可重試錯誤
4. **超時設置**: 合理設置超時避免無限等待
5. **監控告警**: 斷路器OPEN狀態需要告警

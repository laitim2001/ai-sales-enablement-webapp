# Security Module - RBAC & Audit System

## 核心模式

### RBAC權限檢查
```typescript
// 標準權限驗證模式
checkPermission(user, Resource.CUSTOMERS, Action.DELETE)
hasPermission(user.role, Resource.PROPOSALS, Action.CREATE)

// 資源所有權檢查
await checkOwnership(user, resourceId, Resource.PROPOSALS)
```

### 審計日誌記錄
```typescript
// 所有敏感操作必須記錄
await auditLog.log({
  action: AuditAction.LOGIN,
  userId: user.id,
  resource: Resource.CUSTOMERS,
  severity: AuditSeverity.INFO,
  ipAddress: req.ip,
  userAgent: req.headers['user-agent']
})
```

### 加密模式
```typescript
// 敏感字段自動加密/解密
await encryptFields(data, ['email', 'phone'])
await decryptFields(data, ['email', 'phone'])
```

## 文件結構

- `rbac.ts` - 角色權限定義和檢查
- `audit-log.ts` - 審計日誌核心接口
- `audit-log-prisma.ts` - Prisma實現層
- `field-level-permissions.ts` - 字段級權限控制
- `action-restrictions.ts` - 操作級別限制
- `encryption.ts` - 數據加密服務
- `backup.ts` - 自動備份系統
- `azure-key-vault.ts` - Azure密鑰管理

## 關鍵約定

1. **權限優先**: 所有API端點必須先驗證權限
2. **審計必記**: CREATE/UPDATE/DELETE操作必須記錄
3. **加密透明**: 使用 `encryptFields()` 自動處理敏感數據
4. **測試覆蓋**: 每個權限規則必須有測試用例

## 依賴關係

- `@prisma/client` - 數據庫訪問
- `lib/auth` - 用戶認證狀態
- `lib/errors` - 統一錯誤類型

# Authentication Module - JWT & Azure AD

## 核心模式

### 雙令牌認證
```typescript
// 登入 - 生成雙令牌
const { accessToken, refreshToken } = await loginUser(user, deviceContext)

// 驗證 - 中間件自動處理
const user = await authenticateRequest(request)

// 刷新 - 延長會話
const newTokens = await refreshAccessToken(refreshToken)
```

### Azure AD SSO
```typescript
// OAuth流程
const authUrl = await initiateAzureADLogin()
const user = await handleAzureADCallback(code)
```

## 文件結構

- `token-service.ts` - JWT生成、驗證、刷新
- `azure-ad-service.ts` - Azure AD OAuth整合
- `request-auth.ts` - 請求認證中間件

## Token配置

- **Access Token**: 15分鐘過期，用於API訪問
- **Refresh Token**: 30天過期，用於刷新Access Token
- **Cookie設置**: HttpOnly, Secure, SameSite=Strict

## 關鍵約定

1. **安全Cookie**: 永遠使用 `httpOnly: true, secure: true`
2. **設備追蹤**: 記錄 `deviceId`, `ipAddress`, `userAgent`
3. **過期處理**: 自動返回401並觸發前端刷新流程
4. **Azure AD優先**: 企業用戶優先使用SSO

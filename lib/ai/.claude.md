# AI Module - Embeddings & OpenAI

## 核心模式

### 向量嵌入生成
```typescript
// 為文本生成1536維向量
const embedding = await generateEmbedding(text)

// 批量處理
const embeddings = await generateEmbeddings(texts)
```

### 語義搜索
```typescript
// 基於向量相似度的搜索
const results = await semanticSearch({
  query: "產品規格",
  topK: 10,
  filters: { category: 'PRODUCT_SPEC' }
})
```

### AI內容生成
```typescript
// 提案生成
const proposal = await generateProposal({
  customerId,
  template,
  context: knowledgeBase
})
```

## 文件結構

- `embeddings.ts` - OpenAI Embeddings API
- `openai-client.ts` - OpenAI客戶端配置
- `semantic-search.ts` - 向量搜索實現

## 向量配置

- **模型**: `text-embedding-ada-002`
- **維度**: 1536
- **相似度**: Cosine Similarity
- **索引**: pgvector HNSW

## 關鍵約定

1. **批量優化**: 使用 `generateEmbeddings()` 處理多文本
2. **錯誤重試**: OpenAI API調用需要重試機制
3. **成本控制**: 記錄token使用量
4. **混合搜索**: 結合全文搜索和向量搜索

## 依賴關係

- `openai` - OpenAI官方SDK
- `lib/knowledge` - 知識庫集成
- `lib/resilience` - 重試和斷路器

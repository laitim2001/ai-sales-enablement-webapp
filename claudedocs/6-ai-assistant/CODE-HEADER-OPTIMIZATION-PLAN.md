## 📝 統一格式標準

### 標準模板

```typescript
/**
 * @fileoverview [文件用途簡述 - 1-2行]
 * @module [模組路徑]
 *
 * ## 功能說明
 * [2-3行核心功能描述]
 *
 * ## 主要職責 (或 API規格)
 * - 職責1 - 簡短說明
 * - 職責2 - 簡短說明
 * - 職責3 - 簡短說明
 *
 * ## 相關文件
 * - `/path/file1` - 用途說明
 * - `/path/file2` - 用途說明
 *
 * @created [YYYY-MM-DD]
 * @lastModified [YYYY-MM-DD]
 */
```

### 長度指南
| 文件類型 | 推薦行數 |
|---------|---------|
| 簡單工具函數 | 15-25行 |
| 標準組件/API | 25-40行 |
| 複雜核心模組 | 40-50行 |
| **最大限制** | **50行** |

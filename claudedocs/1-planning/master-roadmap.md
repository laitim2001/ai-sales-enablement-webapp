## 🔄 開發方法論

### 敏捷開發流程
- **Sprint週期**: 2週/Sprint
- **每日站會**: 15分鐘同步
- **Sprint回顧**: 每Sprint結束
- **持續集成/部署**: GitHub Actions

### 質量保證
- **代碼審查**: 所有PR必須經過審查
- **自動化測試**: 單元測試 + E2E測試
- **測試覆蓋率目標**: >80%
- **UAT測試**: 每個Sprint完成後

### 技術棧
- **前端**: Next.js 14, React, TypeScript, shadcn/ui
- **後端**: Next.js API Routes, Prisma ORM
- **數據庫**: PostgreSQL
- **AI服務**: Azure OpenAI (GPT-4)
- **整合**: Microsoft Graph, Dynamics 365
- **測試**: Jest, Playwright
- **部署**: Azure App Service

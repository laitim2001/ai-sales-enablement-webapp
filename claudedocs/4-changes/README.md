# 📝 變更記錄

> **受眾**: AI助手、開發團隊、項目經理

## 📂 文檔分類

### **核心記錄** (最新記錄在頂部)
- `DEVELOPMENT-LOG.md` - 開發日誌 (每次重要會話後更新)
- `FIXLOG.md` - Bug修復日誌 (每次修復後更新)

### **決策記錄**
- `mvp2-sprint-adjustment-decision.md` - Sprint調整決策記錄

### **分類變更**
- `architecture-changes/` - 架構變更記錄（按時間歸檔）
- `scope-adjustments/` - 範圍調整記錄（按時間歸檔）

---

**維護規則**:
- ⚠️ **強制**: 新記錄必須添加在文件最頂部（保持時間倒序）
- 📝 **開發日誌**: 每次重要開發會話後更新
- 🐛 **修復日誌**: 每次Bug修復後立即記錄
- 📦 **歸檔**: 超過3個月的變更記錄移至7-archive/

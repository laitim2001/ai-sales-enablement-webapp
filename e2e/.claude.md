# E2E Tests - Playwright End-to-End Testing

## 核心模式

### 頁面對象模式
```typescript
// e2e/pages/LoginPage.ts
export class LoginPage {
  constructor(private page: Page) {}

  async goto() {
    await this.page.goto('/login')
  }

  async login(email: string, password: string) {
    await this.page.fill('[name="email"]', email)
    await this.page.fill('[name="password"]', password)
    await this.page.click('button[type="submit"]')
  }

  async expectLoginSuccess() {
    await expect(this.page).toHaveURL(/\/dashboard/)
  }
}
```

### 測試場景
```typescript
import { test, expect } from '@playwright/test'

test.describe('Knowledge Base Flow', () => {
  test.beforeEach(async ({ page }) => {
    await page.goto('/login')
    await page.fill('[name="email"]', 'test@example.com')
    await page.fill('[name="password"]', 'password')
    await page.click('button[type="submit"]')
  })

  test('user can create knowledge document', async ({ page }) => {
    // 導航到創建頁面
    await page.click('text=新建文檔')
    await expect(page).toHaveURL('/dashboard/knowledge/create')

    // 填寫表單
    await page.fill('[name="title"]', 'Test Document')
    await page.fill('[name="content"]', 'Test content...')
    await page.selectOption('[name="category"]', 'PRODUCT_SPEC')

    // 提交
    await page.click('button:has-text("創建")')

    // 驗證成功
    await expect(page).toHaveURL(/\/dashboard\/knowledge\/\d+/)
    await expect(page.locator('h1')).toContainText('Test Document')
  })

  test('user can search knowledge documents', async ({ page }) => {
    await page.goto('/dashboard/knowledge')
    await page.fill('[placeholder="搜索"]', 'product')
    await page.press('[placeholder="搜索"]', 'Enter')

    await page.waitForSelector('.search-results')
    const results = page.locator('.search-result-item')
    await expect(results).toHaveCountGreaterThan(0)
  })
})
```

## 測試命令

```bash
# 運行所有E2E測試
npm run test:e2e

# UI模式（推薦開發使用）
npm run test:e2e:ui

# 特定測試套件
npm run test:e2e:knowledge
npm run test:e2e:knowledge:create
npm run test:e2e:knowledge:search
```

## 關鍵約定

1. **真實數據**: 使用測試環境的真實數據庫
2. **清理狀態**: 每個測試後清理創建的數據
3. **等待策略**: 使用 `waitForSelector` 而非 `wait(ms)`
4. **選擇器**: 優先使用 `text=`, `role=` 而非CSS選擇器
5. **截圖視頻**: 失敗時自動保存截圖和視頻
6. **並行執行**: 測試間無依賴，可並行運行
7. **頁面對象**: 複雜頁面使用Page Object模式

# Scripts - Development & Maintenance Tools

## 核心模式

### 健康檢查腳本
```javascript
// scripts/health-check.js
async function healthCheck() {
  const checks = {
    database: await checkDatabase(),
    redis: await checkRedis(),
    openai: await checkOpenAI(),
    azureAD: await checkAzureAD()
  }

  const allHealthy = Object.values(checks).every(c => c.healthy)
  console.log(allHealthy ? '✅ All systems healthy' : '❌ Some systems unhealthy')

  process.exit(allHealthy ? 0 : 1)
}
```

### 數據庫初始化
```bash
#!/bin/bash
# scripts/init-db.sh

echo "Creating database..."
psql -U postgres -c "CREATE DATABASE ai_sales_enablement;"

echo "Enabling pgvector..."
psql -U postgres -d ai_sales_enablement -c "CREATE EXTENSION IF NOT EXISTS vector;"

echo "Running migrations..."
npx prisma migrate deploy

echo "Seeding data..."
npx prisma db seed
```

### 環境設置
```javascript
// scripts/setup-local-env.js
const fs = require('fs')
const path = require('path')

function setupEnvironment() {
  const envTemplate = `
DATABASE_URL="postgresql://postgres:password@localhost:5432/ai_sales_enablement"
JWT_SECRET="your-secret-key"
OPENAI_API_KEY="sk-..."
AZURE_AD_CLIENT_ID="..."
AZURE_AD_CLIENT_SECRET="..."
AZURE_AD_TENANT_ID="..."
  `.trim()

  const envPath = path.join(__dirname, '..', '.env')

  if (fs.existsSync(envPath)) {
    console.log('⚠️  .env already exists')
    return
  }

  fs.writeFileSync(envPath, envTemplate)
  console.log('✅ .env created successfully')
}
```

## 腳本分類

### 開發工具
- `setup-local-env.js` - 本地環境快速設置
- `dev-reminder.js` - 開發流程提醒
- `quick-fix.js` - 常見問題快速修復

### 數據庫工具
- `init-db.sql` - PostgreSQL初始化
- `db-optimization.sql` - 性能優化SQL
- `enhanced-db-optimization.sql` - pgvector HNSW索引

- `run-tests.js` - 統一測試執行
- `run-integration-tests.ts` - 整合測試運行器
- `uat-test-runner.js` - UAT測試自動化

- `health-check.js` - 系統健康檢查
- `backup/database-backup.ts` - 自動數據庫備份
- `backup/file-system-backup.ts` - 文件系統備份

### 負載測試
- `load-test-runner.js` - 負載測試執行器（autocannon）

### 索引維護
- `check-index-sync.js` - 索引同步檢查

## 執行方式

### Node.js腳本
```bash
node scripts/health-check.js
node scripts/setup-local-env.js
```

### TypeScript腳本
```bash
tsx scripts/run-integration-tests.ts
tsx scripts/debug-workflow.ts
```

### Shell腳本
```bash
bash scripts/init-db.sh
bash scripts/check-phase-index.sh
```

### NPM腳本
```bash
npm run env:setup
npm run test:workflow:setup
npm run fix:all
```

## 關鍵約定

1. **冪等性**: 腳本應可重複執行不出錯
2. **錯誤處理**: 明確的錯誤信息和退出碼
3. **日誌輸出**: 使用emoji和顏色提升可讀性
4. **參數支持**: 支持命令行參數配置
5. **確認提示**: 危險操作需要用戶確認
6. **文檔註釋**: 每個腳本包含usage說明

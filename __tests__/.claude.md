# Tests - Unit & Integration Testing

## 核心模式

### 單元測試
```typescript
import { describe, it, expect, jest } from '@jest/globals'
import { checkPermission } from '@/lib/security/rbac'

describe('RBAC Permission Check', () => {
  it('should allow admin to delete customer', () => {
    const user = { id: 1, role: Role.ADMIN }
    const result = checkPermission(user, Resource.CUSTOMERS, Action.DELETE)
    expect(result).toBe(true)
  })

  it('should deny sales rep to delete customer', () => {
    const user = { id: 2, role: Role.SALES_REP }
    const result = checkPermission(user, Resource.CUSTOMERS, Action.DELETE)
    expect(result).toBe(false)
  })
})
```

### Mock模式
```typescript
// Mock Prisma
jest.mock('@/lib/prisma', () => ({

```

### 整合測試
```typescript
import { POST } from '@/app/api/auth/login/route'
import { NextRequest } from 'next/server'

describe('Login API', () => {
  it('should return tokens on successful login', async () => {
    const request = new NextRequest('http://localhost/api/auth/login', {
      method: 'POST',
      body: JSON.stringify({ email: 'test@example.com', password: 'password' })
    })

    const response = await POST(request)
    const data = await response.json()

    expect(response.status).toBe(200)
    expect(data).toHaveProperty('accessToken')
    expect(data).toHaveProperty('refreshToken')
  })
})
```

## 測試命令

```bash

npm test

# 監視模式
npm run test:watch

# 覆蓋率報告
npm run test:coverage

# 工作流測試
npm run test:workflow
```

## 關鍵約定

1. **測試組織**: 測試文件路徑對應源文件路徑
2. **命名規範**: `*.test.ts` 或 `*.spec.ts`
3. **Mock優先**: 外部依賴（DB、API）必須Mock
4. **覆蓋率**: 核心業務邏輯要求80%+覆蓋率
5. **隔離性**: 每個測試獨立，不依賴執行順序
6. **快速執行**: 單元測試應在3秒內完成

## 依賴關係

- `jest` - 測試框架
- `@testing-library/react` - React測試
- `@testing-library/jest-dom` - DOM斷言
- `ts-jest` - TypeScript支持
